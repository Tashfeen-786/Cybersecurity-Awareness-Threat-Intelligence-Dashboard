What a Tier 1 SOC analyst actually does

  • Monitor the queue — triage NEW alerts first (sorted by severity/risk), starting with CRITICAL and HIGH.
  • Validate the indicator — is it syntactically valid? Is it already known? Is the intelligence stale?
  • Enrich — first/last seen, categories, sources, related alerts, correlation cluster, ATT&CK context.
  • Check for authorized/benign use — shared infrastructure, CDN, security scanner, stale feed entries. This is where most false positives are caught.
  • Correlate — are other indicators, hosts or alerts part of the same cluster? (Correlation = evidence, not attribution.)
  • Decide & document — escalate to Tier 2, keep monitoring, resolve, or mark false positive — always with a written note explaining why.
  • Feed lessons back — false-positive patterns become tuning requests; confirmed threats become detections and awareness material.
🛑
Never: contact/visit the indicator, execute sample files, or assume an IOC match proves compromise. Analysis is defensive and data-only.

IOC lifecycle

Observed → Validated → Enriched → Scored → Investigated → Monitored → Expired/Closed

  • Observed
    Artifact first appears in telemetry or a feed.
  • Validated
    Syntax checked; duplicates recognized.
  • Enriched
    Local context added: categories, sources, clusters, ATT&CK.
  • Scored
    Separate risk and confidence scores assigned.
  • Investigated
    Analyst triage decides relevance.
  • Monitored
    Watched for further observations.
  • Expired / Closed
    Stale, benign or resolved — indicators expire because they go stale.

✅ User incident-response checklist (what YOU should do)

  • Recognize something is wrong (phishing clicked, device lost, odd system behavior).
  • Stop interacting: don't reply, don't revisit links, don't "test" attachments.
  • Report immediately through the known channel (button / alias / helpdesk).
  • Preserve evidence: keep the email, note times, don't delete or power-cycle devices.
  • Change credentials fast if you entered them anywhere (email account first).
  • Follow instructions from IT/security and stay available for questions.
  • Afterwards: complete the recommended awareness module — lessons learned make everyone stronger.
